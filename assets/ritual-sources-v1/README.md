# Historical source photographs for The Ritual

Retrieved 2026-10-27 from the Academy of Korean Studies / Encyclopedia of Korean Culture.

These are genuine source photographs, not generated reconstructions. Original downloads are preserved here; `public/history/` contains web-size versions. Original watermarks, document text and photo colors are retained; no generative editing, recoloring, cropping or text replacement was used.
